# 구동사 학습 플래시카드 앱

## 프로젝트 개요
미국인들이 자주 사용하는 구동사(Phrasal Verbs)를 학습하기 위한 플래시카드 앱입니다. 4지선다형 퀴즈 형태로 구동사의 의미를 맞추고, 정답을 맞추면 해당 구동사를 사용하는 실제 예문을 보여줍니다.

## 주요 기능

### ✨ 학습 기능
- **4지선다형 퀴즈**: 구동사를 보고 의미를 선택하는 형태
- **10개 구동사 단위 학습**: 한 세션당 10개의 구동사를 학습
- **실시간 점수 표시**: 현재 점수와 진행 상황을 표시
- **정답 시 예문 표시**: 정답을 맞추면 해당 구동사를 사용한 실제 예문을 보여줌
- **시각적 피드백**: 정답/오답 시 색상으로 구분

### 📊 점수 관리
- **점수 기록**: 학습 완료 시 점수를 자동 저장
- **점수 조회**: 이전 학습 기록을 확인 가능
- **정답률 계산**: 맞춘 문제 수와 정답률 표시

### 📝 구동사 관리
- **파일 기반 구동사 관리**: words.txt 파일에 구동사와 의미, 예문을 관리
- **구동사 편집기**: 웹에서 직접 구동사를 편집 가능
- **파일 업로드**: 텍스트 파일을 업로드하여 구동사 불러오기

## 사용 방법

### 1. 구동사 파일 준비
`words.txt` 파일에 다음 형식으로 구동사를 추가하세요:
```
구동사,의미,예문
get up,일어나다,"I usually get up at 7 AM to go to work."
pick up,집다,"Can you pick up that book from the floor?"
turn on,켜다,"Please turn on the lights it's getting dark."
```

### 2. 학습 시작
1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. "시작하기" 버튼을 클릭합니다
3. 제시된 구동사의 의미를 4지선다 중에서 선택합니다
4. 정답을 맞추면 해당 구동사를 사용한 실제 예문을 확인합니다
5. 10개의 문제를 모두 풀면 점수가 기록됩니다

### 3. 점수 확인
- 학습 완료 시 최종 점수를 확인할 수 있습니다
- "점수 기록" 버튼으로 이전 학습 기록을 조회할 수 있습니다

## 기능 상세

### 퀴즈 로직
1. 랜덤으로 10개 구동사 선택
2. 각 구동사마다 4지선다 생성 (정답 1개 + 랜덤 오답 3개)
3. 사용자가 선택하면 정답/오답 표시
4. **정답 시 예문 표시**: 실제 사용 예문으로 이해를 돕습니다
5. 다음 문제로 자동 진행

### 예문 기능
- 정답을 맞추면 해당 구동사를 사용한 실제 예문을 표시합니다
- 예문은 미국인들이 실제로 사용하는 자연스러운 표현입니다
- 이해를 돕기 위해 예문에는 해당 구동사가 포함되어 있습니다

### 점수 계산
- 정답: 1점
- 오답: 0점
- 총점: (맞춘 문제 수 / 전체 문제 수) × 100

### 구동사 파일 형식
- UTF-8 인코딩 권장
- 쉼표(,)로 구동사, 의미, 예문 구분
- 예문은 큰따옴표(")로 감싸기
- 한 줄에 하나의 구동사씩 작성

### 기본 포함 구동사
기본적으로 50개의 자주 사용하는 구동사가 포함되어 있습니다:
- 일상 생활: get up, pick up, turn on/off
- 이동: get on/off, go out, come in
- 사회적: run into, look after, get along with
- 감정: give up, look forward to, get over
- 기타: figure out, find out, put up with

## 문제 해결

### 단어가 로드되지 않는 경우
1. `words.txt` 파일이 같은 폴더에 있는지 확인
2. 파일 인코딩이 UTF-8인지 확인
3. 파일 형식이 "구동사,의미,예문" 형식인지 확인
4. 브라우저 콘솔에서 오류 메시지 확인

### 점수가 저장되지 않는 경우
1. 브라우저의 로컬 스토리지가 활성화되어 있는지 확인
2. 시크릿 모드에서 실행 중이 아닌지 확인

### 모바일에서 작동하지 않는 경우
1. 터치 이벤트가 제대로 작동하는지 확인
2. 화면 크기에 따라 레이아웃이 조정되는지 확인
